A collection of Python projects built from scratch while learning Python fundamentals—from basic syntax to advanced programming concepts.

The goal of this repository is to strengthen problem-solving skills, write clean Python code, and document my learning journey through practical projects.

## ▶️ How to Run

### Clone the repository

```bash
git clone https://github.com/ABflames/Python-basic-to-advanced.git
```

### Navigate to a project

For example, to run the Budget Tracker:

```bash
cd Python-basic-to-advanced/budget_tracker
```

### Run the program

```bash
python3 budget_tracker.py
```
